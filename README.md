# MediQueue – Smart Hospital Queue Management System

MediQueue is a web-based hospital queue management system designed to improve patient flow and reduce waiting times in healthcare facilities. The system provides efficient queue handling, emergency patient prioritization, and real-time monitoring.

## Features

- Patient registration
- Queue management system
- Emergency patient handling and prioritization
- Real-time queue monitoring
- User-friendly interface

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Installation

### Clone Repository

```bash
git clone https://github.com/sanskrutidahiphale/MediQueue-Hospital-System.git
```

### Navigate to Project Directory

```bash
cd MediQueue-Hospital-System
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```
